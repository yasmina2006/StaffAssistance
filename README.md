Title: University Staff Payment System
Problem Statement
A university wants to develop a small software system to manage staff members and calculate their salary.
Each staff member in the university has the following information:
    • Staff ID
    • Name
    • Basic salary
However, different types of staff members are paid differently.
Types of Staff
    1. Professor
A professor receives additional payment based on the number of research papers published.
Each research paper adds $200 to the salary.

    2. Lab Assistant
A lab assistant may work extra hours in the laboratory.
Each overtime hour is paid $100.

System Requirements
The system should:
    1. Store information of different staff members.
    2. Display the details of each staff member.
    3. Calculate the salary of each staff member according to their role.
    4. Keep track of how many staff members have been created in the system.
    5. Ensure that all staff types provide their own method of salary calculation.
    6. The university name should remain the same for all staff members.

Tasks
Write a Java program to implement the above system.
Your design should include:
    • Appropriate classes
    • Proper data members
    • Methods to display staff information
    • Methods to calculate salary
